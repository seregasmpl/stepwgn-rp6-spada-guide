Gathers LXM-247VFNi — быстрый старт

9″ Honda CONNECT ナビ (Gathers). Официальный OM: LXM-247VFNi / рядом LXM-247VFLi. Текст JP→RU по 簡単操作マニュアル и 取扱説明書 Honda.

Включение: ENGINE START/STOP в ACCESSORY или ON → экран заставки → последний использованный экран (HOME / аудио / карта).

Самое нужное за 30 секунд

  1. HOME — главный экран с иконками
  2. 現在地 — карта «где я»; повтор при маршруте — голос маршрута
  3. AUDIO — меню источников / экран воспроизведения
  4. − / ＋ — громкость (аудио / нави / телефон — зависит от того, что сейчас звучит)
  5. Ключ питания аудио — ON/OFF аудио (не двигатель); 長押し — 画質調整 (яркость/контраст)
  6. Ключ панели — открыть слот DISC / SD
JP (簡単操作):
HOME キー → 設定/情報 / 電話 / 目的地検索
AUDIO キー → ソース選択
現在地 キー → 地図
− / ＋ キー → 音量
Перевод: HOME → настройки / телефон / поиск цели.
AUDIO → выбор источника.
現在地 → карта текущего места.
− / ＋ → громкость.
За рулём — громкость так, чтобы слышать улицу. Телефон лучше на стоянке. Навигация Gathers и CarPlay/Android Auto не синхронизируют маршруты: задали маршрут в одном — сбросится в другом.

Открыть / закрыть панель

ジェスチャー: 画面下から上へスライド → パネル開
キー → [モニター Open] / [DISC Eject]
無操作 ≈15秒 → 自動閉（警報音あり）

Или ключ панели → тап モニター Open / DISC Eject.
Без действий ~15 с — автозакрытие (перед этим звуковой сигнал; сигнал слышен даже если «звук операций» выключен).

ナビゲーション — карта и маршрут

Задать цель и построить маршрут

  1. На экране 現在地 тап 目的地検索 → меню целей
  2. Способ: 名称 (название) / 住所 (адрес) / дом / карта / история…
  3. Ввод → 検索 → выбрать объект из списка
  4. 目的地にする → условия поиска → 案内開始
目的地検索 → 名称／住所 → 検索 → 目的地にする → 案内開始
Поиск цели → название/адрес → поиск → «сделать целью» → «начать ведение».

Полезные экраны

  • 現在地画面 — карта без/с маршрутом, иконки пробок, ETC-полос и т.д.
  • 交差点案内 / リアル交差点案内 — схема перекрёстка
  • 自宅 — цель «домой» (сначала зарегистрировать дом в настройках нави)
  • 経由地 — промежуточная точка
Карта и знаки — по данным на момент выпуска карты; реальность может отличаться. Не полагайтесь только на нави при сложных манёврах.

オーディオ — источники, диск, SD

Выбрать источник

  1. Нажать AUDIO → AUDIOメニュー
  2. Если уже играет источник — снова AUDIO, чтобы вернуться в меню
  3. Тап нужного источника (FM/AM, USB, Bluetooth, Disc, SD…)

USB / iPhone / Android

車両のUSB接続ジャックに接続
iPhone: Lightning-USB
Android: 指定USBケーブル
USBメモリー: 直接またはコード
Подключайте к USB-разъёму автомобиля (под крышкой в салоне).
iPhone — Lightning-USB; Android — кабель производителя; флешка — напрямую или переходник.

Диск

  1. Ключ панели → モニター Open
  2. Вставить CD/DVD лейблом вверх → панель закроется, начнётся воспроизведение
  3. Извлечь: ключ → DISC Eject (или 長押し ключа панели — принудительный eject)

SD-карта

  1. Открыть панель → вставить SD этикеткой вверх до щелчка
  2. Закрыть панель ключом
  3. Музыка/видео с SD, запись в Music Rack (по OM)

Bluetooth Audio

HOME → 設定／情報 → Bluetooth®／インターナビ設定 → Bluetooth®の設定 — та же регистрация, что для телефона (см. ниже).

Экран воспроизведения (пример USB)

  • Список / папки, play/pause, prev/next
  • スキャン / リピート / ランダム
  • Seek-bar — перемотка тапом/свайпом
  • Видео с USB — отдельный экран (если поддерживается)

電話 — Bluetooth hands-free

Зарегистрировать телефон

  1. HOME → 設定／情報
  2. Bluetooth®／インターナビ設定
  3. Bluetooth®の設定
  4. На телефоне включить Bluetooth
  5. Bluetooth電源設定 → ON
  6. Bluetooth機器の設定／登録 → 設定する
  7. カーナビから検索
  8. Выбрать имя устройства → 登録する
  9. Сверить passkey → はい
После связи вверху экрана — иконки Bluetooth и уровня сигнала. Синхронизация 電話帳 / 履歴 — в меню телефона/BT.

Позвонить

  1. HOME → 電話
  2. 番号入力 / 電話帳 / よくかける / 履歴
  3. Тап иконки オフフック (трубка «поднять»)

Принять / завершить

着信中 → 応答
通話終了 / 通話画面を閉じる
音量: − / ＋（通話中）
Входящий → 応答 (ответить).
Конец разговора / закрыть экран звонка — кнопки на экране звонка.
Громкость разговора — −/＋ во время звонка.
По возможности не разговаривайте на ходу — остановитесь в безопасном месте.

設定／情報 — дерево настроек

HOME → 設定／情報. Семь блоков (как в практике Clicccar + OM):

  1. NAVI設定 — карта, маршрут, голос, отображение знаков
  2. AV設定 — звук, эквалайзер, DVD/запись
  3. 情報設定 — телефонная книга, ETC и прочая «информация»
  4. Bluetooth®／インターナビ設定 — BT, InterNavi
  5. システム設定 — безопасность, hard key, руль, часы, камера, версия ПО
  6. iPod設定 — при использовании iPod
  7. 音量設定 — уровни по типам звука

Часто нужное в システム設定

  • ハードキー / オプションボタン動作 — что делает кнопка ④
  • ステアリングスイッチ — назначение кнопок руля для аудио/телефона
  • Часы / синхронизация с приборкой
  • Настройки камеры / парктроников
  • ジェスチャー操作での開閉 — вкл/выкл жеста открытия панели

ETC / 後席会話 / камеры / Total Care

ETC・ETC2.0

  • При ON зажигания и проезде антенны/КПП — подсказки на экране
  • История / данные бортового ETC / срок карты — в 設定／情報 → информация ETC
  • ETC2.0: голос ITS, uplink, подсказки безопасности, объезд пробок (по зоне покрытия)

後席会話サポート

後席会話サポート アイコンをタップ → マイクへ発話
後席スピーカーから出力
※後席→前席の増幅は不可
使用中はオーディオ音量が下がる
Тап иконки 後席会話サポート → говорите в микрофон ГУ → звук идёт в задние динамики.
Обратно (сзади → вперёд) усиления нет.
Пока функция включена, громкость аудио приглушается. Громкость — в 音量設定.

フロント／リアカメラ

При R — задняя камера с линиями. Фронт / Multi-View — по комплектации; линии и калибровка — в システム設定. См. также Камеры / Multi-View.

Honda Total Care

С карты 現在地 или HOME → Honda Total Care: парковки, погода, сообщения Honda, Premium (подписка). Нужна регистрация сервиса Honda.
